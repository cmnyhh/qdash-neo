# qdash-neo

把 QQ 群 / 私聊接进 [DSH](https://github.com/deepseek-ai/dsh) 的聊天机器人插件。

它不是一个独立的机器人框架，而是 **DSH 的一个插件**：复用 DSH 的模型、会话、工具和权限体系，
QQ 消息进来就是一次对话，回复由模型自己决定要不要发。

## 能做什么

- 群聊与私聊，白名单控制谁能触发
- **模型自己决定要不要开口** —— 不想说话就一个字都不发，不靠概率硬挡
- `@`、叫名字、拍一拍都能叫醒它
- 看图（需要视觉模型）
- 长期记忆：记住聊过的人和事，每天自动写总结
- 角色卡：给它一个人设，语气和话多话少都写在卡里
- 自带控制台，改配置不用重启宿主
- 群管理（踢人）可选，按 QQ 号白名单校验，默认关闭

## 快速开始

### 1. 准备

- Node.js 22+
- 一个 DSH（0.2.x）
- 一个 OneBot v11 实现（NapCat / Lagrange.OneBot / LLOneBot 都可以）

### 2. 安装

```bash
npm i qdash-neo
npx dsh --profile web --patch node_modules/qdash-neo/cordis.patch.yml
```

> `--patch` 要放在 `--port`、`--no-open` 这类启动参数**之前**，否则会被当成子命令选项而报错。

### 3. 配置

打开控制台 `http://127.0.0.1:7800/`
（用户名 `admin`，口令打在宿主启动日志里，搜「控制台登录口令」）。

最少填三项：

| 在哪 | 填什么 |
|---|---|
| 连接 | `onebot.wsUrl` —— OneBot 的 WebSocket 地址，如 `ws://127.0.0.1:3001` |
| 连接 | `onebot.token` —— OneBot 的 access token（没配就留空） |
| 谁能触发 | `policy.whitelist` —— 允许私聊你的 QQ 号 |

群聊还需要 `policy.groupWhitelist` 填群号。

### 4. 试试

私聊发一句「在吗」。

## 它怎么决定要不要说话

这是它和多数 QQ 机器人不一样的地方：**默认不会每条都回**。

| 情况 | 行为 |
|---|---|
| 有人 `@` 它、叫它的名字、拍一拍 | 一定回 |
| 有人在提问（哪怕没 `@`） | 大概率回 |
| 别人之间聊天、聊它不懂的话题 | 由模型判断，多数时候只是在旁边看着 |

判断依据写在通用提示词里（**不是**靠回复概率硬挡）：这话是不是冲它来的、现在插一句合不合时宜。

**话多话少属于角色卡**。通用提示词只负责"怎么判断"，性格写在你自己的角色卡里 —— 想让它是话痨或冷淡，改角色卡就行，不用改插件。

## 配置

控制台里都能改，保存即生效（标注「需重启」的除外）。最常动的几项：

| 配置 | 默认 | 说明 |
|---|---|---|
| `agent.model` | `deepseek-v4.1-flash` | 用哪个模型 |
| `agent.reasoningEffort` | `high` | 思考强度 |
| `policy.groupTrigger` | `agent` | 群消息怎么触发：`agent` 每条都交给模型判断 / `mention` 只回 `@` / `judge` 先用小模型筛一遍 |
| `policy.replyChance` | `0.95` | 过完闸门后再掷一次骰子，`1` = 不掷 |
| `memory.enabled` | `true` | 长期记忆 |
| `proactive.enabled` | `false` | 允许它排期后主动开口（默认关，见下） |
| `tools.qqAdmin` | `false` | 群管理能力，**开启后还要配 `tools.adminOwners` 才能生效** |

### 关于主动发言

默认**关闭**。开启后，模型可以在觉得「过一会儿值得再说」时给自己排个期
（`[[LATER:30]]`），到点再判断一次——想说就说，不想说依旧什么都不做。

半夜不打扰是硬性的：`proactive.quietHours` 默认 `23:00–07:00`，这段时间到点也不会唤起。
还有 `proactive.maxPerDay` 兜底，防止它一天排十次。

## 常见问题

**它不怎么说话？**
先看控制台里的会话记录。如果 `withheld` 在涨，说明模型写了内容但没调发送工具——那是「它决定不说」，不是故障。想让它更活跃，改角色卡。

**它太爱说话？**
调低 `policy.replyChance`（这是硬闸），或者在角色卡里写清楚「你话不多」。

**看不到图片？**
需要视觉模型，把 `agent.model` 换成支持图片的。

**控制台打不开？**
默认只监听 `127.0.0.1:7800`。远程访问用 SSH 隧道：`ssh -L 7800:127.0.0.1:7800 user@host`，然后浏览器打开 `http://127.0.0.1:7800/`。

**换了 `DSH_HOME` 之后配置全没了？**
数据库跟着 `DSH_HOME` 走。它是 SQLite WAL 模式，迁移时要把 `.db`、`-wal`、`-shm` **三个文件一起复制**，只拷 `.db` 会丢数据。
